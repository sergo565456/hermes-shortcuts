# Сборка шорткатов Hermes на iPhone (один раз, для мейнтейнера)

Шорткаты собираются **один раз**, потом ими делятся по ссылке iCloud. В самих шорткатах нет ни адреса, ни
токена: они берут их из файла `hermes.json`, который пишет «Hermes Setup». Поэтому ссылки безопасно публиковать.

Названия действий даны по русскому интерфейсу iOS 17/18, в скобках английские. Где я не уверен в точном
переводе, стоит пометка «(?)». Если действие не находится, ищи по английскому названию или по ключевому слову
(«словарь», «URL», «файл»).

**Как добавить действие:** в шорткате нажми поле «Поиск действий» внизу и введи название.
**Как вставить переменную:** нажми на поле и выбери переменную в полосе над клавиатурой. Ещё можно долго нажать
на поле и выбрать «Выбрать переменную».

---

## Подготовка на сервере
В MobaXterm выполни:
```
hermes shortcuts pair
```
Появится QR-код. В нём адрес сервера и токен, поэтому **не делай скриншот и никому не показывай**. После
сканирования выполни `clear`.

---

## 1. «Hermes Setup» (сканирует QR и сохраняет настройки)
1. Открой «Команды» → **+** → вверху переименуй в **Hermes Setup**.
2. Добавь **«Сканировать QR-код или штрихкод»** (Scan QR or Barcode) (?).
3. Добавь **«Получить словарь из ввода»** (Get Dictionary from Input) (?). Ввод подставится сам: «QR/штрихкод».
4. Добавь **«Получить значение из словаря»** (Get Dictionary Value): «Значение» для ключа `token` в «Словаре».
5. Добавь **«Если»** (If): «Значение словаря» → **«имеет любое значение»** (has any value).
   - Ветку «Если» оставь пустой.
   - В ветку **«Иначе»** перетащи **«Показать предупреждение»** (Show Alert) с текстом `Это не QR Hermes`,
     а под ним **«Остановить эту команду»** (Stop This Shortcut).
6. После **«Конец Если»** добавь **«Сохранить файл»** (Save File):
   - Ввод: нажми на синее слово и выбери **«Словарь»** (результат шага 3).
   - Папка: **Shortcuts** (стоит по умолчанию).
   - Раскрой действие (стрелка ›): **«Спрашивать, куда сохранить»** (Ask Where to Save) **выключи**,
     **«Подпуть»** (Subpath) = `hermes.json`, **«Перезаписать, если файл существует»** (Overwrite If File Exists)
     **включи** (?).
7. Добавь **«Показать предупреждение»** (Show Alert) с текстом `Hermes paired`.
8. Нажми ▶︎, разреши доступ к камере и отсканируй QR из терминала. Должно появиться «Hermes paired».
9. Проверь: «Файлы» → «iCloud Drive» → «Shortcuts» → там лежит `hermes.json`. Если iCloud Drive выключен, смотри
   «На iPhone» → «Shortcuts».

## 2. «Ask Hermes» (вопрос голосом через Siri)
Шаги 1–6 — это **блок настроек**. Он одинаковый во всех шорткатах Hermes.

1. **«Получить файл»** (Get File):
   - Папка: **Shortcuts**.
   - **«Показать окно выбора документов»** (Show Document Picker) **выключи** (?).
   - **«Путь к файлу»** (File Path) = `hermes.json`.
   - **«Ошибка, если не найдено»** (Error If Not Found) **включи** (?).
2. **«Получить словарь из ввода»**. Ввод: «Файл».
3. **«Получить значение из словаря»**: ключ `url` в «Словаре».
4. **«Задать переменную»** (Set Variable): имя `HermesURL`, значение «Значение словаря».
5. Ещё раз **«Получить значение из словаря»**: ключ `token`. Ввод нажми и выбери **«Словарь»** из шага 2,
   а не предыдущее значение.
6. **«Задать переменную»**: имя `HermesToken`, значение «Значение словаря».
7. **«Диктовать текст»** (Dictate Text). Раскрой его и поставь «Прекратить слушать» → **«После паузы»** (?).
8. **«Получить содержимое URL»** (Get Contents of URL):
   - В поле URL вставь переменную `HermesURL` и сразу за ней, без пробела, допиши `/v1/ask?format=text`.
   - Раскрой действие (›, «Показать больше»):
     - **«Метод»**: `POST`.
     - **«Заголовки»** → «Добавить новый заголовок»: ключ `Authorization`, значение `Bearer`, **один пробел**,
       затем вставь переменную `HermesToken`.
     - **«Тело запроса»**: **JSON** → «Добавить новое поле» → **«Текст»**: ключ `text`, значение
       «Продиктованный текст».
9. **«Произнести текст»** (Speak Text). Ввод: «Содержимое URL».
10. Назови шорткат **Ask Hermes**. При первом запуске iPhone спросит доступ к `hermes.json` и к адресу сервера,
    отвечай **«Всегда разрешать»**. Проверка: «Привет, Siri, Ask Hermes» → «Сколько будет два плюс два?».

## 3. «Hermes» (меню «Поделиться»)
1. Новый шорткат **Hermes**. Нажми ⓘ («Сведения») → включи **«Показывать в меню „Поделиться“»**. В блоке
   «Получать» сверху выбери: URL, текст, веб-страницы Safari, изображения, PDF, файлы. «Если нет входных данных»
   → **«Запросить»** → «Текст».
2. **Блок настроек** (шаги 1–6 из «Ask Hermes»). Проще всего скопировать его из «Ask Hermes»: выдели действия
   и выбери «Скопировать», потом вставь здесь.
3. **«Выбрать из меню»** (Choose from Menu), подсказка `Hermes:`, пункты: `Summarize`, `Remember`, `Remind`, `Post`,
   `Auto`. Внутрь каждого пункта добавь **«Текст»** с тем же словом маленькими буквами (`summarize`,
   `remember`, `remind`, `post`, `auto`).
4. После **«Конец меню»** добавь **«Задать переменную»** `Action` = «Результат меню».
5. **«Получить содержимое URL»**:
   - URL: `HermesURL` + `/v1/share`.
   - Метод `POST`, заголовок `Authorization` = `Bearer ` + `HermesToken`.
   - Тело запроса **«Форма»**: поле «Текст» `action` = `Action`; поле «Текст» `text` = **«Входные данные команды»**
     (Shortcut Input).
6. **«Получить значение из словаря»**: ключ `reply` из «Содержимого URL» → **«Показать результат»** (Show Result).

---

## 4. «Hermes Photo» (фото как задача)
1. Новый шорткат **Hermes Photo**.
2. **Блок настроек**.
3. **«Сделать фото»** (Take Photo) (?), а для галереи **«Выбрать фото»** (Select Photos).
4. **«Конвертировать изображение»** (Convert Image) → **JPEG**, качество около 0,7. Формат HEIC сервер не принимает.
5. **«Выбрать из меню»**: `Receipt`, `Whiteboard`, `Document`, `Auto`. Внутри каждого пункта **«Текст»** с тем же
   словом маленькими буквами. После меню добавь **«Задать переменную»** `Action` = «Результат меню».
6. **«Получить содержимое URL»**: URL `HermesURL` + `/v1/share`, `POST`, заголовок `Authorization` = `Bearer ` +
   `HermesToken`. Тело **«Форма»**: «Текст» `action` = `Action`; поле типа **«Файл»** `file` =
   «Конвертированное изображение».
7. **«Получить значение из словаря»** `reply` → **«Показать результат»**.

## Как получить ссылку iCloud
1. Открой шорткат в приложении «Команды».
2. Нажми на название вверху или ⓘ → **«Поделиться»** (значок ⤴).
3. Выбери **«Скопировать ссылку iCloud»** (Copy iCloud Link). Ссылка вида `https://www.icloud.com/shortcuts/…`.
4. Вставь ссылки в README вместо `ICLOUD_LINK_SETUP`, `ICLOUD_LINK_ASK`, `ICLOUD_LINK_SHARE`, `ICLOUD_LINK_PHOTO`.

**Перед тем как делиться,** открой каждый шорткат и убедись, что в заголовке `Authorization` стоит переменная
`HermesToken`, а не сам токен. В опубликованных шорткатах не должно быть ни адреса, ни токена.

## Если что-то не работает
- **«Файл не найден»:** запусти «Hermes Setup» ещё раз. Проверь, что файл называется именно `hermes.json`,
  а не `hermes.json.txt`.
- **Ошибка 401:** сменился токен, или в заголовке нет пробела после `Bearer`. Выполни `hermes shortcuts pair`
  и снова запусти «Hermes Setup».
- **Нет соединения:** у быстрого туннеля сменился адрес. Выполни `hermes shortcuts pair` и пересканируй QR.
- **QR не сканируется:** выполни `hermes shortcuts pair --invert`, уменьши шрифт или разверни окно терминала.

## Безопасность
- `hermes.json` синхронизируется с iCloud. Сквозное шифрование будет только с **«Расширенной защитой данных»**
  (Advanced Data Protection). Выбрать для папки Shortcuts хранение только на телефоне, пока iCloud Drive включён,
  нельзя. Вариант с токеном внутри шорткатов не лучше: шорткаты тоже синхронизируются через iCloud, а токен
  уходит с каждым шорткатом, которым поделился.
- Если телефон потерян или QR кто-то видел, смени токен:
  `hermes config set SHORTCUTS_TOKEN "$(openssl rand -hex 32)"` → `hermes gateway restart` →
  `hermes shortcuts pair` → снова «Hermes Setup».
